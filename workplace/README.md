## 为什么要把 Mystery Method 迁移到职场？

面试、谈薪、跨部门撕扯与向上管理，本质上都是**高信息不对称下的社交动态与框架争夺（Frame Control）**。
很多候选人简历能力过硬，但在面试前 5 分钟就被面试官带入“自证清白（过度迎合 / 跪求认可）”的低价值框架，导致明明做成了项目却讲得像在汇报检讨。

本目录剥离原著中任何操纵或欺骗性技巧，只保留其最硬核的 **结构化阶段模型（M3）、高价值信号展示（DHV）、合规性测试拆解（Shit Test / 压力面应对）与推拉校准（Push-Pull）**，映射为三套可直接用于职场的博弈指南：

| 专题文档 | 解决的职场痛点 | 映射的核心心智模型 |
| --- | --- | --- |
| [面试框架控制：破解压力面与单向审讯](interview-frame-control.md) | 一被质疑就慌乱解释、把面试变成单方面挨批、气场被压制 | **框架控制（Frame Control）** + **废物测试拆解（Congruence Test）** + **故事嵌入式 DHV** |
| [谈薪博弈：锚定价值与底牌防守](salary-negotiation.md) | 被 HR 压价、过早亮出底牌、不好意思谈涨幅 | **投资度模型（Compliance / Investment）** + **抽离校准（Willingness to Walk Away）** |
| [向上管理：对齐预期与边界防御](managing-up.md) | 接下无边界烂摊子、做了苦劳没功劳、汇报抓不住老板注意力 | **阶段推进（A→C→S：注意力→信任舒适→拍板执行）** + **预选择效应（Social Proof）** |
